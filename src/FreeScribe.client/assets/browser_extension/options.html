FreeScribe for OSCAR

Control FreeScribe during a visit and put the finished note into OSCAR (or any web EMR). The extension talks only to FreeScribe on this computer and keeps no notes.

In FreeScribe, click Chrome extension in the sidebar, turn it on and copy the code. Leave the port as it is unless you changed it in FreeScribe.

Using it during a visit

  1. Open the patient's chart in OSCAR. Press Alt+Shift+R (or the FreeScribe button) to start recording. The chart's patient is linked to the session, so forms get the name, date of birth, health card and address from OSCAR.
  2. At the end, press it again: FreeScribe stops, transcribes and writes the note.
  3. Click in the encounter note box where the note should go, then press Alt+Shift+N (or Insert into EMR in the FreeScribe button). Check the note before you sign it.
  4. Select text in the chart (a medication list, a past history) and right-click Add to FreeScribe visit context to give the AI that background.

Change the shortcuts at chrome://extensions/shortcuts.
